# workflow-to-agent

## 절차
1. `templates/step-table.md`로 단계표를 만든다(판단/생성 라벨).
2. **MVP**: 아는 코드(LangGraph 등)로 그래프를 먼저 만든다. 순서는 엣지로 정한다. 범위를 좁게 잡고, 파일 위치를 미리 지정한다.
3. **에이전트 버전**을 만든다. 시스템 프롬프트에는 역할과 목록만 넣는다.
4. **순서 강제**: 각 도구가 `current_step`을 읽고, 어긋나면 `out_of_order`로 거절하고 `next_tool`을 반환하게 한다. 패턴은 `examples/stepguard.py`를 따른다. 첫 도구는 강제로 호출해도 된다.
5. 대화와 상태는 **영속 저장**한다(메모리 전용 체크포인터만 쓰지 않는다).
6. 세 버전을 같은 입력으로 돌려 `templates/baseline-log.md` 형식으로 비교한다.

## 원칙
- 프롬프트로 순서를 지키게 하는 것은 "기도하는 단계"다.
- 도구 수는 최소로 유지한다. 컴팩트하지만 안정적으로 만든다.
