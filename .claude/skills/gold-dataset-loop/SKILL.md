# gold-dataset-loop

## 절차
1. 골드셋 위치와 형식을 확인한다(예: `eval/gold.jsonl`: `{"input": ..., "expected": ...}`). 없으면 사람이 확정할 표본 목록부터 만든다. 정답은 모델이 만들지 않는다.
2. 현재 에이전트를 골드셋에 돌리고 결과를 `eval/runs.jsonl`에 기록한다.
3. 오답을 **구체적으로** 분류한다. 예: "카테고리까지는 맞고 가맹점명이 틀림". "틀렸다" 수준으로 끝내지 않는다.
4. 오답 유형별로 보정 위치(스킬, 프롬프트, 도구, 데이터)를 제안하고 하나씩 고친다.
5. 다시 돌려 통과율을 비교한다. 다른 항목이 회귀하지 않았는지 확인한다.
6. 변경과 수치를 `docs/decisions/`에 남긴다.
