# folder-summarizer

## 규칙
- **기본 도구(Glob, Read, Grep, Write)만 쓴다.** 새 도구나 스크립트를 만들지 않는다.
- 결과는 대화에 쏟지 않고 파일로 저장한다. 대화에는 경로와 3줄 요약만 보고한다.

## 절차
1. Glob으로 구조를 파악한다. 파일이 많으면 하위 폴더별로 서브에이전트에 맡긴다.
2. 각 파일은 앞부분과 제목 위주로 읽는다(전체 덤프 금지).
3. `<폴더>/SUMMARY.md`에 목적, 구성, 핵심 개념, 읽는 순서를 저장한다.
4. `<폴더>/index.md`에 `templates/index.md` 형식으로 경로와 한 줄 설명을 저장한다.
