# retro

## 범위
- 기본: **현재 프로젝트**의 세션 기록, 최근 7일
- 글로벌(`~/.claude/history.jsonl`, 다른 프로젝트)은 민감할 수 있으니 **사용자가 명시적으로 허락할 때만** 본다.

## 절차
1. 세션 파일 위치를 확인한다(`~/.claude/projects/<project>/`). 전부 읽지 말고 메타정보와 사용자 메시지 위주로 본다. 양이 많으면 서브에이전트에 맡긴다.
2. 찾을 것
   - 같은 요청을 반복하거나 중복 실행한 것
   - "어디까지 됐어?" 같은 확인 질문 반복
   - 실패와 재시도가 반복된 작업과 그 원인
   - 너무 긴 출력, 잡음 세션, 잘못 시작해서 늦게 멈춘 작업
3. 각 패턴에 대해 CLAUDE.md 규칙, 새 스킬, 템플릿 중 무엇으로 고칠지 제안한다.
4. 결과를 `docs/retro/YYYY-MM-DD.md`에 저장하고, 대화에는 상위 3~5개만 요약한다.
