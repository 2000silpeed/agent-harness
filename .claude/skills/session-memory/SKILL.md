# session-memory

## 저장 (주제 종료 시)
`memory/YYYY-MM-DD-<topic>.md`에 아래 형식으로 짧게 남긴다. 압축하지 말고 표지판만 남긴다.
```
- 날짜: YYYY-MM-DD
- 주제: <한 줄>
- 요약: <핵심 한 줄>
- 원본: <파일 경로, 커밋, PR, 문서 링크>
- 열린 이슈: <있으면>
```

## 회상 (주제 재등장 시)
1. `memory/`에서 주제를 찾는다(Grep).
2. 원본을 읽고 **육하원칙**(누가, 언제, 어디서, 무엇을, 어떻게, 왜)으로 상세 요약을 만들어 현재 작업에 쓴다.
3. 미리 모든 것을 상세 요약해 두지는 않는다. 다시 불릴 때만 만든다.
