# interview-me

## 절차
1. 주제와 최종 산출물(스펙, 설계서, 결정)을 확인한다.
2. AskUserQuestion으로 **한 번에 1~4개씩** 질문한다. 선택지에는 추천안을 첫 번째로 두고 이유를 단다.
   - 순서: 목표 → 사용자·상황 → 범위(하는 것/안 하는 것) → 제약(시간, 비용, 권한) → 완료 조건 → 위험
3. 답에서 모호한 부분을 다시 파고든다. 이미 답한 것은 다시 묻지 않는다.
4. 충분해지면 `docs/specs/<topic>.md`에 정리한다. 결정 사항, 열린 질문, 다음 단계를 담는다.
5. (선택) 인터뷰가 쌓이면 사용자 선호를 `docs/specs/_preferences.md`에 요약한다.

## 주의
- 오래 걸리므로 다른 세션 작업과 병행하길 권한다.
