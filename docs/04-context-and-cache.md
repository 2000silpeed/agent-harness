# 4. 컨텍스트 배치와 캐시

## 컨텍스트는 대화보다 넓다 [강의]
Claude 앱의 컨텍스트 표시를 보면 메시지 말고도 많은 것이 들어 있습니다. MCP 도구, 시스템 프롬프트, 스킬, 메모리 파일, 시스템 도구, MCP 서버 인스트럭션, 오토컴팩트 버퍼가 함께 들어갑니다. "죄다 툴 툴 툴." `/context`로 확인합니다.

## KV 캐시는 텍스트 매칭 [강의]
- 앞에서부터 글자가 같아야 캐시가 적중합니다. "토씨 하나 틀리면 안 됩니다." 띄어쓰기 하나만 달라도 그 지점부터 깨집니다.
- 배치 순서는 **고정 → 변동**입니다.
  ```
  [시스템 프롬프트(고정·짧게)] → [스킬·도구] → [날짜·시간·사용자 값] → [찾아온 자료] → [질문]
  ```
- 가장 흔한 실수는 날짜를 맨 앞에 넣는 것입니다.
- 세션 중간에 스킬이나 도구 목록 앞부분을 고치지 않습니다. 바꿔야 하면 새 세션을 준비합니다.
- Anthropic API는 캐시를 **명시적으로 켜야** 합니다. TTL은 5분과 1시간이 있고 가격이 다릅니다. `response_metadata`/usage에서 cache read/creation 토큰을 확인합니다.

## 컨텍스트 예산 [강의]
- 큰 코드베이스는 탐색만으로 70% 이상을 씁니다. **80%를 넘으면 품질이 떨어집니다.**
- 멀티 에이전트의 출발점은 **컨텍스트 격리**입니다.
- 출력 토큰은 입력보다 약 5배 비쌉니다. 판단 출력은 클로즈드 퀘스천으로 좁힙니다.
