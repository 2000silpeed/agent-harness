# 작업 방식
- 요구가 모호하면 추측하지 말고 한 번에 하나씩 묻는다.
- 코드를 바꾸기 전에 계획(수정 대상, 순서, 테스트 방법)을 쓰고 승인을 받는다. 범위가 바뀌면 계획으로 돌아간다.
- 코드를 고치면 관련 테스트를 돌린다.
- 완료는 테스트 결과와 실제 변경으로 보고한다. 확인하지 못한 것은 "미확인"이라고 적는다.
