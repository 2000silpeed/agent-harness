# 클로즈드 퀘스천 판단 프롬프트

출력 토큰이 입력보다 비싸므로, 판단은 선택지로 좁힙니다.

## 주제 변경 감지
```
직전 주제 요약: {prev_topic}
새 입력: {user_input}
새 입력이 직전 주제와 다른 주제인가? 1(다름) 또는 0(같음)만 출력하라.
```

## 자료 존재 여부
```
인덱스: {index_md}
질문: {question}
이 인덱스 아래에 답의 근거가 있는가? Y 또는 N만 출력하라.
```

## 경로 선택
```
다음 중 하나만 출력하라: FAQ | CLARIFY | HANDOFF | DECLINE
```
