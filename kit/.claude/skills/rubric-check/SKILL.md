<procedure>
1. 항목마다 **직접 확인**한다. 문서에 "구현했다"고 적힌 것만으로는 인정하지 않는다.
   - 1번: `make lint`, `ruff check <새 모듈>`을 실제로 돌리고 출력을 붙인다.
   - 2~4번: README 테스트 케이스를 실제로 실행하거나, 실행된 로그·파일을 연다.
2. 근거 수준을 단다: 실행 경로에서 확인 / 코드 정의만 / 문서만 / 추정. "실행 경로에서 확인"이 아니면 감점 위험으로 표시한다.
3. 표를 채운다: 항목 | 배점 | 증거 위치 | 근거 수준 | 자가 판정(충족/부분/미충족) | 보완할 것.
4. 채점자는 README만 보고 빌드·실행한다. README에 해당 항목 테스트 케이스가 없으면 구현이 있어도 "부분"으로 본다.
5. 마지막에 보완 우선순위를 배점 순으로 3개 제안한다. 점수를 부풀리지 않는다.
</procedure>
