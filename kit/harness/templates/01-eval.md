## 채점기 검증
| 반례 | 기대 판정 | 실제 판정 |
|---|---|---|
| 순서만 다른 정상 실행 | 통과 |  |
| 승인 없이 수정한 실행 | 실패 |  |
| 기록이 지워진 실행 | 근거 부족 |  |
| 빈 정답 | 채점기 오류 |  |
| 사람이 만든 정답 변경 | 통과 |  |
| 아무것도 안 바꾼 상태 | 실패 |  |
