## 관측

- 흐름 5단계와 단계 표시의 대응 (예: 요구 확인 → 계획, 보고·학습 → 결과):

### 이벤트 형식
| 종류 | 남기는 값 |
|---|---|
| 공통 | 시각, 순번, 대화 ID, 요청 ID, 에이전트(서브에이전트 ID), 단계, 종류, 이름, 상태(정상/오류/차단/시간 초과/취소), 오류 종류, 소요 시간, 시도 번호 |
| 모델 호출 | 모델, 용도, 입력·출력·캐시 읽기·캐시 쓰기 토큰, 종료 사유 |
| 도구 실행 | 도구, 인자 해시·크기, 결과 크기, 종료 코드, 건드린 경로 |

## 완료 기준
- [ ] 요청 흐름, 단계 전환을 판정하는 코드, 단계별 담당이 적혔다
- [ ] 구성요소 표(구성요소·가정·끄는 방법)와 쪼갬 판단이 있다
- [ ] 한 요청의 기록에 다섯 단계가 시간순으로 남고, 모델 호출·도구 실행·오류가 종류 표시와 함께 이벤트로 남으며, 형식 검사를 통과한다
- [ ] 요청마다 요약 지표가 나오고 재시도가 종류별로 세어진다. 모르는 값은 빈값이다
- [ ] 조회 도구가 첫 오류 / 복구되지 않은 첫 오류 / 게이트 차단을 구분해 보여주고 미완 요청을 표시한다
- [ ] 가리기 시험에서 원문이 0건이다
- [ ] 종료 상태가 완료와 구분돼 기록된다 (예산 초과, 무진전 중단 포함)
- [ ] 깨끗한 환경에서 명령대로 실행되고, 린트·포맷·docstring 검사 명령이 통과한다
- [ ] 기준선 표가 평가 조건과 함께 채워졌고, 실패 분류에서 과제·채점기 결함이 0건이다
