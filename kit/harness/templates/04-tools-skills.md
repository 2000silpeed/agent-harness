## 완료 기준
- [ ] 편집 형식이 선택 근거(모델별 적용 성공률)와 함께 정해졌고 가드레일 시험을 통과했다
- [ ] 도구마다 명세(설명, 인자 예시, 반환 상한, 오류 종류)와 단위 테스트가 있다
- [ ] 읽기·검색·테스트 도구의 출력 상한과 잘림 안내가 구현됐다
- [ ] 스킬마다 호출 시험 결과(적중·오발)가 있다
- [ ] 도구 정의 총 토큰, 도구 오류율, 편집 실패율이 적혀 있고 평가 회귀가 없다
