## 평가 기준 (슬라이드 원문)

| 평가 기준 | 내용 |
|---|---|
| Python 코드의 일반적인 개발 기준 준수 [10점] | 들여쓰기, 공백, 줄바꿈 등 PEP8 코드 스타일 준수 [3점] / 변수·함수·클래스의 명명 규칙 준수 및 import 정리 [3점] / 주요 함수의 역할·입출력을 설명하는 docstring 및 필요한 주석 작성 [4점] |
| Coding Assistant의 개발 시작 전 작업 계획 구체화 및 리뷰 [10점] | 개발 시작 전 요구사항, 작업 범위, 완료 조건 정의 [2점] / 수정 대상, 작업 순서, 테스트 방법이 포함된 구체적인 계획 작성 [3점] / AI의 계획 리뷰를 수행하고, 수정 의견이 있으면 계획에 반영하는 절차가 있는가 [3점] / 계획 승인 후에만 코드를 변경을 시작하고, 작업 범위 변경 시 재검토 [2점] |
| Memory 활용 및 Self-Improving Harness 구성 [10점] | 프로젝트 규칙·작업 경험을 Memory에 저장하고 세션 종료 후에도 유지 [2점] / 새로운 작업에서 관련 Memory를 검색하여 계획·코드 작성에 실제 활용 [3점] / 실행 실패·평가 결과를 바탕으로 Agent가 시스템 프롬프트·Skills·작업 메모리 등 개선안을 생성 [3점] / 개선 전후의 효과와 기존 기능의 정상 동작을 검증하고, 통과한 개선안을 다음 작업에 반영 [2점] |
| Coding Assistant가 작업하는 내용 모니터링 가능 여부 [10점] | 요청별로 계획·리뷰·코드 변경·테스트·최종 결과의 전체 실행 흐름 기록 [3점] / LLM 호출, 도구 실행, Memory 활용, 자기 개선 과정의 결과와 오류 기록 [3점] / 실행 시간, 호출 횟수, 재시도 횟수 등 주요 지표 수집 [2점] / 작업별 로그·Trace를 조회하여 실패 지점과 원인을 확인할 수 있도록 구현 [2점] |
