## 5일차 4강 — 무료 모델 엔드포인트와 Jev 딥 에이전트 실습 (파일 업로드·인용 과제)

> 출처: 「5일차 4강 다시보기」(전사·분석, 45:49 분량), 「5일차 4강 장표」(17장). SDS AX Advanced · 2026-11-06.
> 참고: 앞 약 32분이 설명이고, 뒤(약 33:20~45:47)는 실습 시간이라 발화가 거의 없다.
> 대응 저장소: 루트의 `used_jev_deepagents/`(실습 에이전트)와 `Day05_new/task.md`(과제). 노트북은 쓰지 않았다.

### 핵심 요약 (3~5줄)
- 개인 프로젝트에는 "비용 압박이 무조건 온다." 그렇다고 너무 싼 모델을 쓰면 안 되니, **NVIDIA NIM(build.nvidia.com) 무료 엔드포인트**와 **OpenRouter의 free 모델·스텔스 모델**, 작은 모델을 잘 만드는 **Liquid AI**를 써 보라고 소개했다. 스텔스 모델은 내 스킬·도구가 여러 모델에서 매끄럽게 도는지 시험하는 데 좋다.
- 구글이 공개한 설계·리뷰 스킬(Elephant Goldfish Model)을 예로 "무조건 집단지성"을 강조했다. 내 생각은 남도 했다. 먼저 검색하고 허점만 채워 쓴다.
- 점심 동안 Claude에게 시켜 **jev(디시전 모델) Evaluator**를 데이터셋 항목만 채점하도록 좁혀 정상 동작시켰다. jev는 매우 싸고 반복 실행해도 안정적이다. 평가하려면 먼저 Claude Code 사용 기록을 쌓아야 한다.
- 실습 에이전트 **`used_jev_deepagents`**: 판단 로직을 모두 jev가 맡는 아주 작은 딥 에이전트(파일을 보고 답만 함) + 업로드 파일을 나눠 분석하는 서브 에이전트 + LangChain Agent Chat UI. Claude Code로 띄우되 **API 키는 Claude에게 주지 말고 직접 `.env`에 넣는다.** 이것을 RAG 에이전트의 출발점으로 삼는다.
- **Jev 그라운딩** 경고("근거 밖 사실 → 신뢰하지 마세요")는 사용자에게 보일 필요 없이 **trace에 남기고**, 나중에 싸거나 한가한 시간에 표시된 것만 골라 평가한다. 과제(`task.md`): 텍스트 파일은 정해진 경로에 저장·인용해 답하고, PDF는 거부, 이미지는 모델이 처리 가능한지 확인 후 처리. 약 40분.

### 주요 개념 (개념별 설명, 강사가 강조한 이유 포함)

**1. NVIDIA NIM 무료 엔드포인트**
- build.nvidia.com에서 회원가입만 하면 Free Endpoint 제공. 가중치가 공개된 최신 모델을 NVIDIA가 직접 서빙한다(예: 키미 3.1, 딥시크. Mistral Large 4처럼 가중치 미공개 모델도 서빙). 미디어 모델도 많다. MiniMax는 강사는 안 쓴다("너무 바보 같아서").
- Free Endpoint만 체크하면 **45개**. 강사는 "키미 3.1만 쓸 것 같긴" 하다고.
- 주의: Claude Code 같은 데 연동은 "별로" — **자주 끊어진다**. 대신 개발·서비스 개발 중 테스트에는 공짜라 유용하고 강사도 많이 쓴다.
- 강조 이유: 비용 압박을 줄이되 너무 저렴한(품질 낮은) 모델은 피하는 방법.

**2. OpenRouter — free 모델과 스텔스 모델**
- 여러 모델을 한 엔드포인트·한 곳의 비용으로 쓰게 하는 AI 게이트웨이 중 가장 큰 회사. 올해 8~9월쯤 Stripe(미국 결제 회사)에 매각됐다고 함.
- 모델 검색어에 `free`를 치면 무료 모델이 잔뜩 나온다.
- **스텔스 모델**: 공개 전 테스트용으로 모델 이름은 "~알파", 회사 이름은 stealth로 숨긴다. GLM 5.3 플래시도 이렇게 시험됐다. 성능이 좋았던 경우가 많다.
- 쓰임새: 테스트 모델이라 메인 작업엔 꺼려지지만, "내가 개발한 지금 뭐 스킬이나 뭐 이런 툴이나 이런 녀석들이 다양한 모델에 좀 매끄럽게 지원이 되는가" 확인할 때 좋다. 그래서 계정을 꼭 가지고 있으라고 했다.

**3. Liquid AI — 작은 고성능 모델**
- Hugging Face에 오픈소스 모델을 많이 푼다. 작은 모델인데 성능이 좋다. 8일차에 배울 가드레일 관련 모델도 8B 이하로 제공.
- 대부분 Apache 라이선스라 비즈니스 사용에 걱정이 적다.

**4. 구글 공개 스킬(Elephant Goldfish Model, EGM)과 집단지성**
- 구글이 소프트웨어 개발 시 설계(디자인)·리뷰에 쓰는 스킬을 공개. 강사도 점심에 봐서 아직 검토는 안 했다. (저장소 확인: Day05_new/task.md:23 — `https://github.com/google/elephant-goldfish-model`)
- 볼 곳은 **스킬 폴더**: 리뷰 루프·개별 리뷰 프로세스, 부트스트랩(브레인스토밍 단계), Apache 2.0, 에이전트는 OpenAI 스펙 — "오픈 AI 스펙이어도 여러분들이 충분히 클로드로 바꾸실 수가 있고".
- "무조건 집단지성입니다. 내가 생각한 거 남이 무조건 했을 수 있어요." 최대한 빨리 검색 → 남이 만든 것의 허점 → "그것만 채워 넣어서 내 걸로 빨리". AI가 만드는 건 어렵지 않은 시대이고 새 아이디어 발굴이 어려우니, 많이 봐야 떠오른다.

**5. jev로 고친 Evaluator**
- 점심 동안 Claude에게 "디시즌 모델로 만든 이벨루에이터 정상 동작하게 좀 바꿔봐라" 정도로만 부탁. Claude가 **데이터셋 항목만 채점하도록 좁혀** 테스트했다. 데이터셋이 부족해 효과는 아쉬움.
- "이 디시즌 모델은 … 가격이 일단 말도 안 되게 저렴하고 반복해서 돌리면 돌릴수록 그 안정성이라는 게 LLM은 좀 무너지는데 그 안정성이라는 측면에서도 얘는 꽤나 좀 지켜주더라."
- 평가를 하려면 **Claude Code 사용 기록**부터 쌓아야 한다 → 그래서 실습 에이전트를 돌린다.

**6. `used_jev_deepagents` — jev가 판단하는 작은 딥 에이전트**
- 실습 자료 루트(A5 말고 아래쪽)에 있다. "세 개의 파일로만 구성", 실제로는 로직을 조립하는 구조.
- 판단 로직은 "죄다 제브(jev)를 쓰도록" 했다. jev를 딥 에이전트에서 어떻게 쓰는지 확인하는 용도. (저장소 확인: used_jev_deepagents/README.md:17, :21 — 무엇을 검색할지·어떤 청크를 남길지·얼마나 생각할지 등 '판단'은 Jev에 위임, 문장은 채팅 모델이 씀)
- 역할은 "진짜 파일만 보고 답하는" 정도. `create_deep_agent` 코드에서 **서브 에이전트** 하나를 만든다 — 사용자가 업로드한 파일을 청킹·분석. "레그(RAG) 에이전트에 아주 작은 버전". (저장소 확인: used_jev_deepagents/src/agent/graph.py:35-58 — 서브 에이전트 `chunk-analyst`, 설명 "Extract facts from one /retrieved/ file")
- 프론트엔드: CLI에 익숙지 않은 사람을 위해 LangChain이 제공하는 프론트엔드(Agent Chat UI)를 그대로 넣었다. (저장소 확인: used_jev_deepagents/README.md:61, :274 — Agent Chat UI, 포트 3001)

**7. 키 관리 — "클로드한테 그 키 주시면 안 돼요"**
- OpenRouter 키: 구글 시트 **G열**에 개인별로 할당(성함과 같은 행). **자기 키만** 쓴다 — 남의 키를 쓰면 크레딧 제한 때문에 "두 배로 빨리" 닳는다.
- Langfuse 연동은 **선택**. 쓰려면 Secret Key와 Public Key를 추가하되, **Langfuse 프로젝트를 새로** 만든다 — 오전 프로젝트는 Claude Code 기록을 쌓는 중이라 섞이면 나중에 파악하기 힘들다. (저장소 확인: used_jev_deepagents/.env.example:16-20 — `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, "Optional")
- 키를 채울 때: Claude에게는 "그 .env 내가 채워야 되는 것만 비워서 만들어달라"고 하고, 키는 다른 곳에서 손으로 복사해 넣는다. "클로드한테 그 키 주시면 안 돼요. 무조건 유출되는 겁니다."
- .env가 없어서 실행해도 모델 호출이 안 되는 것은 **의도한 동작**.

**8. Jev 그라운딩과 trace 기반 후속 평가**
- 답 아래에 "Jev 그라운딩 … 이 답은 남긴 근거 밖에 사실을 넣은 것으로 판단되어 그대로 신뢰하지 마세요."가 붙는다. 테스트용 힌트로 일부러 사용자에게 보여 줬다. (저장소 확인: used_jev_deepagents/src/middleware/turn_plan.py:474-478 — 메시지 원문, used_jev_deepagents/src/harness.py:589-595 `check_grounding` "최종 답이 남긴 근거 안에 있는지 묻는다")
- 실제로는 사용자에게 보여 줄 필요 없이 **trace에 남기면 된다**. "이 지금 내용을 다 검토하기에는 우리 LLM이 너무 비쌉니다." → 싼 모델로 간단 검토만 하고 "체크 필요할 것 같은데?" 표시 → 비용이 싸거나 시스템 사용이 덜한 시간에 그것들만 골라 Eval.
- 3강의 "트레이스를 남길 때부터 평가 대상을 정한다"는 숙제에 대한 한 가지 답이다.

**9. 과제 `task.md` — 파일 읽기·쓰기와 이미지 처리 가능 여부**
- 업로드한 파일 또는 이미 가진 파일을 처리할 수 있어야 한다.
  - 텍스트 파일: **정해진 경로에 저장**하고 **인용**해서 대답.
  - PDF: **거부**("굳이 처리하지 않을게요"). 코드로 짜면 되지만, 사이즈가 크고 파싱 품질에 따라 헷갈릴 수 있어 범위에서 뺐다.
  - 이미지: **모델이 처리 가능하면** 처리해서 대답. 강사는 "5.6 루나"로 세팅해 이미지가 되지만, 모델을 바꾸면 처리 불가능할 수 있다(텍스트만 되는 모델). 이 여부를 **확인하도록** 구성해야 한다.
- 크게 기능 두 가지: ① 파일 리드·라이트 ② 이미지 처리 가능한 모델인지 확인.
- 저장 경로는 세션마다 나눌 필요 없이 **공용**("세션까지 분리하면 너무 더 복잡해질 수 있으니까").
- (저장소 확인: Day05_new/task.md:2-5 — 위 세 규칙과 같은 문구)

### 실습/데모 내용 (명령어, 파일 구조, 프롬프트, 코드 조각 등 원문 그대로 보존)

**1) 실행 요청 (Claude Code 새 세션)**
- 새 세션을 열고 `used_jev_deepagents` 폴더를 참조시킨다(장표 표기 `@used_jev_deepagents`). 지시(발화 그대로):
```
이거 백엔드 프론트엔드 실행하고 싶은
만약 모델 키가 없거나 잘못되었다면
수정 요청해줘
```
- 환경에 따라 Node.js 설정·패키지 다운로드가 더 필요하고 Claude가 함께 처리한다. .env가 아직 없으니 "뭘 넣어주세요"라고 요청하기를 기대한다.
- 강사 화면: 넣어 둔 OpenRouter 키가 만료돼 **401** → 키를 바꿔 달라는 응답(영어로).

**2) 키 넣기**
```
(.env) 내가 채워야 되는 것만 비워서 만들어달라
```
- 그다음 키는 직접 붙여넣기. OpenRouter 키는 시트 G열, jev 키는 기존 위치, Langfuse는 선택(새 프로젝트).
- (저장소 확인: used_jev_deepagents/.env.example:1-20 — `LLM_PROVIDER`, `ANTHROPIC_API_KEY`, `OPENROUTER_API_KEY`, `TYPESAFE_API_KEY`(Jev), `EXA_API_KEY`, Langfuse 키)

**3) 프론트엔드에서 시험**
- 모델 키까지 넣으면 Agent Chat UI 화면. 간단히 질문하거나 파일을 업로드해 본다.
- PDF 업로드: "PDF를 처리할 수 없어서…" 실패. 강사 설명: 업로드 버튼은 UI에 있지만 백엔드에 그 기능을 구현해 놓지 않았다.
- 오류가 나면 Claude가 대신 실행했으니 이렇게 시킨다:
```
백엔드 로그 검토에서 오류 난 게 뭔지 봐줘
```
- 수강생 질문(OpenRouter 모델에 크레딧이 없다는 내용) → "엔트로픽은 안 되는 게 맞고요. 오픈라우터는 됩니다." (저장소 확인: used_jev_deepagents/README.md:13-14 — 기본은 Anthropic API(`claude-haiku-5-5`), `.env`에 `LLM_PROVIDER=openrouter`를 넣으면 OpenRouter)

**4) 도구·서브 에이전트 호출 확인 (프론트엔드에서 질문)**
```
네가 가진 도구가 뭐냐.
```
```
서브에이전트한테 현재 탐색 가능한 파일을 확인하고 그 리스트랑 주요 내용 전달하라고 해줘
```
- 콜 기록: 서브 에이전트 호출 도구 사용, 타입은 따로 지정하지 않아 **general-purpose**, 실제 호출은 **`task`** 도구(프로세스 생성). "존재하지 않습니다"가 여러 번 나온 뒤 "탐색을 완료했습니다".
- "지금은 이렇게 스킬스 경로만 보고 있습니다." (저장소 확인: used_jev_deepagents/src/agent/graph.py:45 — `skills=["/skills/"]`)

**5) 과제 받기**
- 강사가 `Day05_new/task.md`로 깃에 푸시했다(앞 화면에도 띄움). `git pull`로 받는다. pull 충돌이 나면 "클로드한테 원래 풀 해결하라고 압박하시면 됩니다."

   - PDF 는 거부.
   - 이미지는 '모델' 이 처리 가능하면 처리해서 대답.

### 강사 팁·주의사항
- 개인 프로젝트 비용은 무료 엔드포인트(NIM, OpenRouter free)로 줄인다. 단 NIM은 Claude Code 연동엔 자주 끊긴다.

- 무엇을 만들기 전에 먼저 검색한다. 남이 만든 것의 허점만 채워 빨리 내 것으로 쓴다(스킬 폴더 구조부터 본다).
