### 핵심 요약 (3~5줄)
- 앞부분은 모델 업계 소식이다. 독파모에 세 팀이 남았고 업스테이지가 **솔라 프로4**를 냈다(툴 콜링이 좋음, OpenRouter 키로 50% 세일 중). LG AI는 **KX1 2.5** API를 무료로 열었다(회사 이메일 필요, 600B 정도). 중국은 큰 모델을 잠그는 중이고, 미스트랄·코히어·세레브라스 동향도 소개했다.
- 본론은 앞 시간에 돌려 둔 **Ouroboros 인터뷰**(플러그인 비교)에 각자 개발 방식대로 답해 **pstack을 포크한 나만의 플러그인** 방향을 정하는 실습이다. 기준은 **Python 기반 코딩 에이전트(디코드)를 튜닝하는 프로젝트**다.
- 인터뷰는 끝나지 않을 수 있으므로 **20턴(질문 20개)이 넘으면 멈추고 만들어 달라고** 한다. 질문에 **빨리 답할수록** 백그라운드 에이전트가 빨리 꺼지고 다음 질문으로 넘어간다. 완성 후 **원본 pstack은 지운다**(중복·충돌).
- 학습용 PC에서는 망가지면 `.claude` 폴더를 지우면 되니 마음껏 실험하라고 했다.
- 끝으로 Claude Code에서 pi로 옮긴 글을 소개하며 무거움·잦은 릴리즈(244회, 이틀 단위)·성능 저하 불만을 전하고, 목적은 "Claude를 버리는 게 아니라 주어진 환경에서 우리 방식에 맞추는 것"이라고 정리했다.

### 주요 개념 (개념별 설명, 강사가 강조한 이유 포함)

**1. 국산·해외 모델 동향 (00:00~10:23)**
- **독파모**: 국가 지원 한국 독자 AI 모델 사업. "스타트업 한 군데 더 탈락을 했고 해서 독파모가 세 팀 남은 걸로 알고 있어요." 세 팀 중 하나가 업스테이지.
- **솔라 프로4(업스테이지)**: "디사이드, 디시즌 모델도 내긴 했습니다"(전사 불명확). 50% 세일 중이라 "여러분들께 드린 오픈라우터 API 키로도 써보실 수가 있어요." 강사 평가는 "일단 툴 컬링[콜링]이 잘해요." 다만 강사가 쓴 것은 "얼리 액세스 버전이어서 학습이 되고 있는 중에 체크포인트를 꺼낸 걸" 쓴 것이라 "지금은 또 다를 수가 있다".
  - 강조 이유: "우리나라 독파모 욕만 할 게 아니라 써보고 욕을 해야 되죠."
- **KX1 2.5(LG AI)**: 강의 당일 API 공개, "공짜래서 회원 가입만 하면 쓸 수 있다", 그런데 회사 이메일 입력을 요구. 크기는 "600B인가 그랬던 것 같아요" — 직접 돌리기 부담스러운 크기.
- **업스테이지 사업 방향**: 10월 뉴스 "업스테이지 내년 수능 영어 출제 AI". 예전엔 모델만 만들고 나머지는 서드파티로 사다가 최근 "다음도 사고 에이전트 하는 회사를 또 한 두 개 사가지고" 자사 모델 기반 에이전트 비즈니스로 확장 중.
- **모티프 테크놀로지**: 성능을 최상으로 찍었는데 독파모에서 "좀 불공정하게 약간 탈락된 느낌", 이후 "도파모 중단됐어요"(세부 사유는 전사 불명확).
- **프런티어 모델 국가기관**: GPU가 "2만장이 안 돼요", "내년 초까지 안 들어올걸요", 슈퍼컴퓨터도 "GPU가 8천몇백장" — "조직만 생겼대요."
- **중국 모델 비공개 전환**: "점점 중국이 모델을 잠궈가고 있어요." 큰 모델을 잠근 지 1년이 넘었고, Qwen은 Qwen Max를 3버전부터 공개한 적이 없다(2·2.5까지는 공개). "QN4 이후에는 어떻게 될지 모르겠습니다." 키미(Kimi)만 다 공개 중이나 "강제하는 게 아니니까" 언제든 멈출 수 있다.
- **해외 모델사**: 미스트랄(프랑스) — 한국 리크루팅이 공격적이었고, 소문으로는 삼성전자용 반도체·피지컬 AI 모델을 **포스트 파인튜닝** 중. OCR도 잘함. 코히어(캐나다) — 한국 진출, "CNS를 통해서 많이 도입". 모델사들이 모델만 팔 수 없어 에이전트 시스템 회사와 손잡는 경우가 많다.
- **세레브라스(Cerebras)**: 자체 운영 클라우드 플레이그라운드에서 Qwen을 "천 몇백 토크 퍼셋[토큰/초]" 속도로 확인 가능 — "QN이 어느 정도인가 확인해보실 때" 유용.
- 이 이야기를 한 이유: "모델이 또 나온다는 소리예요."

  - (저장소 확인: 강의에서 언급한 개발 작업 플러그인 링크 `https://github.com/cursor/plugins/tree/main/pstack` — `Day06_new/info.md:4`)

- 이 작업의 의미: "하네스에 대한 기본 개념을 한번 들어보셨기 때문에 그걸 가지고 나의 하네스를 만드는데 기존에 있는 플러그인들을 활용해서" 만드는 과정.

**6. 빨리 답하기 (31:46~33:09)**

**8. Claude Code 불만과 나만의 환경 (39:15~45:00)**
- 소개한 글: "코드를 작별하고 파이로 넘어갔다"(Claude Code → pi, 정확한 제목 미확인). 1년 넘게 Claude를 쓴 사람의 불만:
  - "클로드가 일단 무거워요. 쓸데없는 게 너무 많습니다." 코드 읽고 쓰면 되는데 아티팩트 같은 기능이 "꼴사나워진다", "시스템 프롬프트 넣는 것도 좀 싫다."
  - 에이전트 md 지원 지연, VS Code IDE 연결(한 번에 한 세션만), GUI 익스텐션 불편, "기능 추가가 앞서는 제품 개발 방식", "다이나믹 워크플로우, 에이전트 팀즈, 울트라 리뷰와 같은 톡큰 미친듯이 뽑아내는 기능들은 추가했는데 관리를 전혀 안 해줍니다."
  - 강사가 특히 강조: "244회의 릴리즈… 이틀 단위로 릴리즈됩니다", "4분의 3 이상의 시스템 프롬트나 도구 설명이 변경돼요. 무슨 말이냐 테스트도 안 하고 내보낸다는 소리예요."
- 강사 체감: "오프스[Opus] 5.5 또 성능이 떨어졌습니다." API가 아니라 "클로드 코드 내에서 떨어졌습니다" — 원인은 모델 너프(양자화)거나 "추가[프롬프트·도구 추가]가 꼬였거나… 보통 꼬인 경우가 많아요."
- **pi 에이전트**를 비교 대상으로 계속 말한 이유: "얘가 워낙 가벼워서 가볍다는 건 커스텀 하기가 쉽다라는 거죠."
  - (저장소 확인: "Pi is a minimal terminal coding harness", 사용자가 자기 작업 방식에 맞게 바꾸는 것이 목표 — `Day06/HARNESSES.md:66-72`; 링크 `Day06/info.md:7`)
- 요즘 개발자들은 코드는 Claude가 해 주니 그 시간에 "내 작업 환경"에 AI가 "유기적으로 결합될 수 있을까 그 환경을 만드시는 작업들을 되게 많이" 한다.
- 사내 에이전트 이야기(지인 전언): "회사에서 만든 에이전트는 별 쓸모가 없더라", "자기가 한 달 동안 한 거 클로드가 이틀 만에 다 했다."
- 결론: "최종 목적은… 클로드를 갖다 버리자라는 얘기는 아니고요. 클로드를 주어진 환경에서 우리한테 우리 속 맛에 맞게 최대한 만드는 작업을 지금 좀 하고 있다."

### 강사 팁·주의사항
- 국산 모델은 "써보고 욕을 해야" 한다. 솔라 프로4 평가는 얼리 액세스 체크포인트 기준이라 지금은 다를 수 있다.
- 인터뷰 답은 "강의용"이 아니라 **자기 프로젝트(4·5일차 이후 프로젝트, 디코드 튜닝)**를 생각하며 해야 한다.
- 계획 단계를 꼼꼼히 할수록 프로그램이 안정적이다 — 느린 질문 시간은 생각할 시간이다.
- **20턴이 넘으면 멈추고 만들게** 하라. 안 그러면 토큰만 쓰고 끝나지 않는다.
- 질문에 **빨리 답하라** — 백그라운드 에이전트가 빨리 꺼져 다음 질문으로 넘어간다.
- 포크해 만든 플러그인이 완성되면 **원본은 반드시 지운다**(중복·충돌).
- 실험은 학습용 PC에서. 망가지면 `.claude`를 지우면 된다. 내 PC에서 충돌 실험을 하면 머리 아프다.
- Claude Code는 릴리즈가 잦아 시스템 프롬프트·도구 설명이 자주 바뀌고, 체감 성능이 Claude Code 안에서 흔들릴 수 있다. 그래도 지금 목표는 Claude를 버리는 게 아니라 우리 방식에 맞추는 것.
